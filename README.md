# Scout Amazon Product Agent

本地 Amazon 店铺找品程序，包含澳大利亚（AU）、加拿大（CA）、美国（US）、荷兰（NL）等站点，具体以界面支持列表为准。程序先按导入店铺链接确定站点，再访问对应 Amazon 店铺获取全部可枚举 ASIN。默认从同站商品页读取月购买量、重量、评价、售价、标题和主图；用户主动接入 SellerSprite 后，可补充同站点、同 ASIN 的月销量。1688 图片匹配在用户确认产品范围后单独启动。

当前版本：`v0.9.50`

## 独立服务与可选数据源

程序不依赖 ChatGPT、Codex 或其他 AI 软件。Amazon 官网后台采集、已确认的 1688 后台匹配、服务守护和事件巡检都由本地程序执行；关闭 AI 不影响它们。电脑须保持开机，Node 服务须运行。

SellerSprite 是可选功能，默认关闭；没有 MCP 配置的同事可正常使用 Amazon 模式。需要时在程序自己的 `config/sellersprite.local.toml` 配置远端 MCP，或设置 `SCOUT_SELLERSPRITE_CONFIG_PATH`，无需安装 AI 或 MCP 宿主。示例为 `config/sellersprite.example.toml`，真实密钥、任务数据和 Cookies 不提交 GitHub。

当前 SellerSprite 多店铺、多批次分析仍由网页逐批发起；使用该模式时保留页面，关闭后需用户明确继续。它不依赖 AI，但尚未像 Amazon-only 和 1688 确认批次一样完整托管到后台。历史恢复和只读轮询不会自动连接 SellerSprite 或重新发起查询。

程序事件巡检每 15 分钟检查 Amazon、每 30 分钟检查 1688；与业务执行器的 30 秒 / 5 秒检查、Windows 服务守护的 60 秒检查分别负责不同工作。事件持久化在 `data/program-monitor.json`，界面及 `GET /api/monitor` 可查看。正常运行、冷却、人工暂停和重复状态不反复提醒。

同事安装与配置见 [独立运行手册](docs/standalone-operations.md)，其他 AI 或本地脚本接入见 [本地 HTTP API](docs/local-api.md)。

### 澳洲、加拿大 FBA 标准信封估费（v0.9.50）

澳洲统一采用用户提供的标准信封表，范围为 ≤33 × 23 × 2.5 cm、≤475g；售价 ≤13 AUD 使用低售价档，>13 AUD 使用高售价档。已知尺寸超限或重量超出表格时需人工配送费，缺尺寸则明确显示标准信封暂估。

加拿大统一采用用户提供的旺季信封件表（≤500g），暂不按日期切换非旺季。售价 <14 CAD 减 0.8 CAD，恰好 14 CAD 不减；最终配送费为（基础费－适用优惠）×1.035，计算和导出保留完整精度，金额仅在显示时保留两位小数。这是用户指定的估算口径，原表旺季适用期为 2026-10-15 至 2027-01-14。

人工配送费优先。页面确认未提供重量时，按对应售价规则的最低重量档暂估，允许初审；售价也缺失时明确标记低售价档假设。完整费表、来源和边界见 [AU / CA FBA 估费规则](docs/fba-rates-au-ca.md)。

### 候选商品六项手工编辑（v0.9.49）

候选商品的利润拆解支持修改售价、1688 单件采购价、Amazon 标题件数、整套采购成本、FBA 配送费和计费重量。修改后自动保存，也可点击“保存修改”，界面显示保存结果；其他利润参数缺失时仍可单独保存，初审继续校验月购买量和重量证据。

修改整套采购成本会按件数换算人工单价，并保留换算精度；修改单价或件数会更新总额。人工输入在刷新、后台重算、后续采集和报价更新时保留，保存失败可重试。正在采集或匹配的商品、已交接的分析版本继续受保护。此版本不调整澳洲、加拿大的自动 FBA 费率、售价门槛或季节规则。

### 采购单价默认值与人工覆盖（v0.9.48）

采购单价未手动修改时，使用已有的 1688 单件采购均价；输入框留空也沿用当前价格，不要求重复填写。人工填写有效单价后，以人工值计算，保存、刷新及后续匹配均保留人工价格。单件价格保留原始精度，整套采购成本仍按单价 × Amazon 标题件数计算；仅改变件数或保存未修改的均价不会误标为人工价。没有均价时保留缺项，初审可先进行，界面会说明采购价格来源。

### 全量采集与候选初审（v0.9.47）

店铺枚举和详情采集保留全部可发现 ASIN，页面没有月购买量标识或标识低于 50 的商品也会保留。采集后，Amazon-only 模式使用当前 ASIN 在店铺卡片或商品页明确的过去一个月 50+ 购买量证据；主动接入 SellerSprite 时也可使用同站点、同 ASIN 的有效近月销量估计，并明确来源。原文、ASIN、数值及口径一起保存，缺失或人工填写的销量不伪装为自动核验证据。旧断点的已观察商品合并去重，人工暂停和已完成任务不会因升级而自动重跑。

重量读取 Item details、技术参数、Facts 等区域，分别保留商品重量和包装重量证据，排除推荐商品、其他 ASIN 和承重量。成功访问详情且页面确认未提供重量时，重量保持空值，FBA 配送费可暂按当前站点配置表的适用最低重量档估算：澳洲、加拿大按 v0.9.50 的售价规则，美国为 3.22 USD；不虚构 75g 重量，也不据此计算头程或完整利润。待采集、失败及异常重量不能作为页面缺重处理。

候选初审与完整利润计算独立：50+ 证据有效且已取得重量或确认页面缺重的商品，可在售价、采购成本或完整利润尚未补齐时初审通过。缺重的最低 FBA 费明确标为暂估，人工价格、重量、采购成本和供应商报价继续保留。

### 利润即时计算与后台匹配（v0.9.38）

每次保存 Amazon 字段或有效 1688 报价时，本地服务立即执行现有利润公式并保存结果，无需 AI。页面通过本地事件流接收更新，断线时由状态轮询补同步；采购成本为空时，仅计算时按 0，成本栏仍为空，并标记“预估利润率（未扣采购成本）”；取得有效报价后自动回填并重算。缺少售价、重量或履约费时仍显示具体缺项。

1688 已确认的固定批次由后台串行继续，页面刷新或切换不会丢失批次。任务编号在提交搜图前保存，重启复用原任务，已完成候选直接取回；匹配仍遵守原有间隔与冷却。页面可暂停后续匹配，人工暂停和访问验证均需要明确恢复。手工成本、报价和交接记录受保护。

### 1688 登录与搜图频率（v0.9.37）

登录身份与图片搜索验证分别显示。专用 Edge 先启动空白页，再打开登录或图片验证页，避免外网页面未加载完成而误报窗口启动失败；重复点击复用当前验证窗口。窗口启动失败不会清除已保存身份。

新版搜图页以已知地址或官方搜图应用标记及可用上传控件共同识别；未找到控件约 15 秒内给出具体原因。顶栏弹层先核对本次上传图片的预览，再单次点击“搜索图片”，普通背景请求不作为搜索已开始的证据。选择图片后，普通页面 60 秒仍未确认本次新图片结果即停止，不重复上传；真正出现人工验证时保留人工处理窗口。连接区显示上传、等待结果、人工验证等阶段及最近错误，窗口打开期间每 3 秒只读取本地状态。卡住时可用“重新打开 1688 验证窗口”恢复，保留登录身份。

1688 搜图由本机队列统一串行处理，实际间隔、额外休息和冷却以采购桥接服务返回的 `ratePolicy` 为准，时间和暂停状态持久化。用户明确启用逐小时试验后，从 90 次/小时开始，完整通过一小时且实际样本足够才加 10 次/小时；见 [速率试验规则](docs/1688-rate-trial.md)。该配置不是平台已验证的最大 HTTP 请求数，也不保证不会触发风控，网页本身还包含图片和资源请求。

遇到滑块或其他人工验证，全队列暂停，取消后台自动挑战重试。人工完成图片验证后，点击“验证完成，继续搜图”才恢复；仅重新登录或刷新状态不会解除暂停。普通 429 按服务器等待时间或至少 5 分钟冷却。每分钟的进度检查仅读取本地状态，不再次访问 1688；每个商品也不再额外调用在线身份校验。

v0.9.36 已修复加拿大站等已支持站点的导出文件名校验，初审 Excel 继续保存到 `D:\铺货筛选`。

### 当前筛选匹配与利润状态（v0.9.35）

1688 图片匹配使用与商品列表相同的全部筛选结果（含搜索、重量、利润和完整度筛选，覆盖全部分页）。商品具备 ASIN 和主图即可找货，无需先取得售价或重量；已匹配、已交接、已淘汰和手工采购成本商品继续受保护。缺失售价时可保存真实供应商报价，目标成本和利润保持为空，待必要参数补齐后按现有公式自动重算。列表直接显示“待计算”及缺少的参数，不再用空白表示。

采集进行中也可点击匹配：先保存 Amazon 断点、等待当前采集退出，再保存固定匹配批次并调用 1688。匹配结束后恢复原采集状态和限流冷却时间；手动暂停不会被恢复。临时暂停租期为 120 秒，匹配页面每 5 秒续期，关闭页面且本地 1688 请求结束后由后台巡检恢复，避免永久停在临时暂停。暂停或等待人工处理的任务在采集工作器退出后可以编辑，保存仍校验采集版本以保护新结果。

### 后台采集与字段监查（v0.9.34）

Amazon 官网任务由本地服务在后台采集，页面关闭不会中断。每批同步读取价格、商品/包装重量、标题、主图、评分及评价数，并逐字段保存有效值、取值来源、检查时间与缺失原因。价格和重量必须通过 ASIN/币种/正数及来源检查；“页面未提供”和“请求失败”分别记录，不用 0 或旧价格补齐。

每个商品页面成功返回后，用同一份 HTML 一次提取全部字段并保存；详情弹窗读取本地结果，不触发 Amazon 重访。页面未提供的字段直接保留缺失说明，不因缺价格或重量自动重复访问，也不跨站补抓重量。只有显式点击“补采缺失字段”才重新访问这类商品。升级时旧版仅因缺字段形成的补采队列也会停止重复访问。

后台每 30 秒巡检任务，批次正常结束后自动继续下一批；请求超过 4 分钟会中止并保存断点。后台失败最多 3 轮。Amazon 验证码或限流先冷却 5 分钟、10 分钟，持续 3 次则显示需要处理，程序不会破解验证。手动暂停不会被自动巡检恢复；可用“继续采集”或“补采缺失”显式恢复。

启动器同时以隐藏窗口启动独立进程守护，每 60 秒检查本地服务。进程退出后重新启动；连续 3 次无响应时，仅重启已核对路径和 PID 的本服务进程。任务与原始采集结果保存在本地 `data` 中，重启后从断点继续，已有完整结果不重复采集。电脑需要保持开机唤醒；重启电脑后再次运行启动器即可恢复。守护日志位于 `%TEMP%\scout-au\watchdog.log`；创建 `data\collection-watchdog.disabled` 可停用进程守护，再启动时可使用 `-NoWatchdog`。

页面显示后台进度、价格/重量等字段统计、最后进展及下次重试时间。采集中可查看、筛选并发起供应商匹配，暂停或完成后可以编辑。原始采集结果独立保存，旧页面的过时快照会被拒绝，避免覆盖后台新数据；人工输入和供应商报价仍受保护。

### 商品售价校验（v0.9.33）

Amazon 售价优先读取当前 ASIN 的主商品价格区，支持金额整数/小数分开渲染的页面。推荐商品、其他变体、划线原价、分期与单位价格不作为当前售价；结构化备用价格须与当前商品和站点币种一致。找不到可靠售价时显示“页面未提供售价”，不会猜测价格或回填旧值。自动价格同时保存取值位置、页面原文、币种及 ASIN 证据。

恢复旧任务时，旧解析器生成的自动售价会标记为“待重新核价”，保留旧值审计，并通过已保存的商品断点重新采集。自动售价、目标采购成本及利润会重新计算；依赖旧价格的初审需要重新确认。手工价格、采购成本及已保存的供应商报价继续保留。已交接采购的只读分析仍按原有新分析版本流程处理。

旧页面的商品详情每批最多额外重试两次，暂停后刷新不会触发无限重试。升级后的 Amazon 官网任务使用上述后台采集机制；SellerSprite 仍需原有手工授权。

## 启动

安装 Node.js 24，在项目根目录打开 PowerShell：

```powershell
node --version
npm ci
.\launch-scout-au.ps1 -NoBrowser
```

打开 <http://127.0.0.1:4173/>。去掉 `-NoBrowser` 可由启动器打开 Edge 窗口。Windows 推荐该启动器，它同时管理本地服务和外部守护；`npm start` 仅启动 Node 服务及服务内调度，不提供 Windows 外部守护。服务只监听 `127.0.0.1`。

仅运行 Amazon 可使用 `.\launch-scout-au.ps1 -NoBrowser -Skip1688Startup`，跳过采购桥启动。1688 为可选服务，安装目录、桥接和登录步骤见 [依赖说明](1688-dependencies/README.md)。启动器会尝试拉起采购桥接，但没有配置或登录 1688 不影响 Amazon 分析。不要并发启动多个采购桥接副本；启动器本身不安装 Windows 开机自启任务。

## 一次任务的流程

1. 导入 XLSX 店铺清单，按有效链接自动识别站点，例如加拿大链接使用 CA / CAD。一个文件的有效链接属于多个站点时，先按国家拆分。
2. 选择月销量档位、最低评价数和星级。“接入 SellerSprite”默认关闭，未配置者直接使用 Amazon 模式；需要 API 月销量时，开启开关并明确连接当前站点。
3. 点击“开始分析”。Amazon-only 任务交给本地后台，关闭网页仍可继续；SellerSprite 模式先枚举店铺，再由页面逐批请求同站点 ASIN 的商品和销量数据，执行期间需保留页面。
4. 每个源 ASIN 保留一行，父 ASIN 仅为关联字段。月销量未知不等于零或低于 50；候选依据可靠数据筛选，缺项和失败原因保留。
5. 需要采购报价时，再打开 1688 专用 Edge 完成登录、验证，并在结果页确认产品筛选范围，明确启动后台图片匹配。没有 1688 时仍可进行 Amazon 分析和人工成本填写。
6. 1688 按下述图片与报价规则计算成本，样本不足不伪造厂家；达到备用样本条件时明确标记低置信度估算。
7. 产品人员补齐或修改售价、采购成本、FBA/FBM、重量、尺寸、装箱和产品费率。人工值保留，利润按当前公式重算，有效值自动保存后可进行初审。
运营不参与系统操作，可接收全部候选产品或仅接收已初审产品的标准 XLSX 导出表。导出完成后文件由本地服务直接保存到 `D:\铺货筛选`，同名文件自动添加序号且不覆盖已有表格；页面会显示实际保存路径，不再另存一份浏览器下载。每行使用稳定的商品任务 ID，并另存批次 ID；竞品主图以 512 × 512 像素、JPEG 质量 92 嵌入工作簿，Excel 中仍按 96 × 96 像素显示，同时保留原图链接和逐行嵌入状态。单张图片失败不会中断整批导出，缺失原因会保留在表中。

## SellerSprite 调用边界

生产流程只允许调用 `asin_detail`（ASIN 详情）和 `competitor_lookup`（查竞品）。不会调用产品研究、销量趋势或相关竞品推荐（asin_competitor）接口来代替目标 ASIN 月销量。

- 页面加载、刷新、心跳、历史恢复和 1688 状态读取不会连接或调用 SellerSprite。
- “接入 SellerSprite”默认关闭；关闭时商品详情来自 Amazon 官方商品页，本次 SellerSprite 工具调用固定为 0。
- 只有开启接入开关并主动点击“连接 SellerSprite”时，通过 POST /api/sellsprite/connect 建立 MCP 会话。GET /api/sellsprite/status 和版本读取只报告本地配置/状态，不连接外部服务。
- 只有用户随后点击“开始分析”或明确重新分析时调用这两个商品工具；页面加载、状态刷新和历史恢复不会触发。
- ASIN 详情按 `runId + provider marketplace + source ASIN` 保存断点；查竞品按 `runId + provider marketplace + month + source ASIN` 保存成功或明确无结果的断点。查竞品请求每批最多 40 个 ASIN，使用 `month: nearly` 的最近 30 天口径。触发 SellerSprite 每分钟访问上限时，当前任务等待 61 秒后继续；已经保存的结果不重复调用。
- 左侧显示持久化的 SellerSprite 历史调用总数；任务记录显示每次任务调用数。
- 任务记录会分别保存 `asin_detail` 与 `competitor_lookup` 的调用次数。

查竞品使用当前售价、子 ASIN 近 30 天销量与销售额、父体月销量与销售额、FBA 运费、履约方式、评分、评价、A+、上架日期、主图及商品/包装重量尺寸。FBA 运费原值优先于本地旧费率估算，产品人员仍可手工覆盖。该接口没有 60 天销量和首次 FBA 有货时间，这两项缺失时保持为空并允许人工补填。当前官方月销量市场表不支持 AU、NL 时，该模式明确拒绝并提示使用 Amazon 页面数据；不能改用 US、DE 或其他站点替代目标商品的销量。子体近月销量只取 `amzUnit`，父体 `units` 不能代替。

## 1688 图片匹配

1688 由已安装的 `1688-procurement-assistant-2.3.0` 桥接统一持有专用 Edge 会话，登录状态保存在该采购助手目录的 `data\1688-session`，Profile 为 `profiles\default`。默认与替代安装布局见 [1688 依赖说明](1688-dependencies/README.md)。找品 Agent 只通过本机采购助手 API 创建受管找厂任务，不打开第二个 Edge、不读取 Cookie，也不把 Cookie 复制到其他 Profile。

登录采用可见专用 Edge，完成后关闭并使用同一 Profile 无头重开验证。在线验证必须同时确认官方域唯一 `unb`、`tracknick`、`work.1688.com` 正常页面和 2xx 响应；登录页、验证码、风控、429 或其他异常均不会标记为就绪。成功结果缓存 30 秒，失败结果缓存 3 秒，不做高频保活刷新。

每个商品的成本样本规则：

- 商品必须有 Amazon 主图；标题和翻译不参与 1688 搜索、资格判断、排序或成本计算。
- 最多读取前 40 个图片搜索候选，并将 Amazon 主图与每个 1688 候选主图在本地计算固定版本的视觉指纹相似度。
- 标准路径的图片相似度必须严格 `> 0.50`。恰好 50% 不通过；没有有效图片相似度结果的候选不进入自动成本计算。
- 标准达标后按图片相似度由高到低排序，再按唯一厂家去重并收集前 10 家有效供应商。
- 报价需使用相同采购单位，并按目标 MOQ 选择可比较的阶梯价。
- 将 10 家报价按人民币单价排序，剔除最低 2 家和最高 2 家。
- 只计算中间 6 家的平均单价。
- 标准达标的唯一厂家少于 10 家时，对具备真实厂家身份、1688 商品链接、有效 MOQ、单位、人民币报价和有效图片相似度结果的候选去重。
- 只要有至少 6 家上述真实有效唯一报价，就取图片相似度最高的 6 家，直接计算算术平均成本和利润率，并持续标记为“低置信度估算”；低于 50% 的厂家不会被伪装成标准匹配通过。
- 图片搜索后仍不足 6 家时不补造厂家，平均成本、盈利判定和粗算利润率保持为空。

页面显示图片相似度和纳入/剔除原因。任务记录保存图片分数、算法版本、图片哈希、已评估/达标数量和报价审计。人工采购成本会覆盖利润计算输入，但不会删除原始 1688 报价证据。旧任务使用旧选取规则时，原计算保留在历史审计中并标记待重新图片匹配，不再作为自动利润依据；人工成本结果不受影响。

每次 1688 找厂都会保存对应的采购助手任务编号。图片任务超时只代表仍在后台队列中，页面会保留任务编号、候选和报价，不再继续创建后续重复任务；恢复时先复用已保存任务编号对应的原任务。出现 `login_required`、`risk_control` 或 `rate_limited` 时，必须回到专用 Edge 人工处理；系统不会绕过验证或自动高频重试。

本机采购服务使用单例恢复：健康检查瞬断只做一次短退避，服务进程掉线时可自动恢复同一受管服务；不会因此自动登录、打开风控页或重复发起业务搜索。最近的风控失败与本机进程掉线会分别显示，不再统一写成“登录断链”。

1688 在任务中断联后，当前任务的候选商品和已经完成的 1688 结果会继续保留。用户在专用 Edge 重新登录、完成必要验证后，再按界面提示明确继续原批次；只读状态刷新不会自动补做，人工暂停不会被登录结果解除。续跑只处理原批次未完成商品，不连接或调用 SellerSprite，已经完成的商品不会重复找厂。左侧分别显示账号身份、图片专项验证和后台队列数量，不能再用“已在线”掩盖图片队列阻塞。

## 目标成本与粗算利润率

默认销售价：

```text
我们的售价 = 竞品当前售价
```

产品人员补填或修改竞品当前售价后，我们的售价、目标成本、粗算利润率和完整经营利润率都会按与竞品同价的规则重新计算。

页面中的站点币种金额会在主值下方显示按当前任务汇率换算的人民币参考值，例如 `$12.00` 下方显示人民币数值（美国站按工作簿使用 7.12）。售价筛选、利润编辑和手工履约费输入会实时更新人民币副值；运营导出表为每个外币金额增加相邻的 CNY 数字列。人民币换算只使用任务汇率，不使用下面的目标采购成本判定公式。

美国站：

```text
目标成本 CNY = 我们的售价 USD × 1.4
```

其他站点：

```text
目标成本 CNY = 我们的售价（当地币种）× 当地币种兑 CNY 汇率 ÷ 5
```

盈利线与粗算利润率：

这里的 85% 是采购成本盈利线，与上面的图片匹配门槛相互独立，不会替代商品核验。

```text
盈利线 = 目标成本 CNY × 85%
可盈利 = 1688 估算均价 <= 盈利线
粗算利润率 = (目标成本 CNY - 1688 估算均价) / 目标成本 CNY × 100%
```

标准模式的“1688 估算均价”是 10 家报价执行 2 / 6 / 2 后的中间 6 家均价；低置信度模式是图片相似度最高 6 家的直接均价。

粗算利润率只保留为 1688 采购价校验。候选排序、初审和运营导出统一使用下面的完整经营利润率。

## 单品经营利润

全局“成本参数”页已删除。每个商品保存独立的输入、来源、公式版本和计算结果；修改 A 商品不会改变 B 商品。通用默认费率为 Amazon 佣金 15%、汇损 1.5%、Marketing 10%、管理费 5%、退货预留 8%；澳洲站按工作簿覆盖为管理费 6%、退货预留 10%、VAT 0%。澳洲站空运按 60 CNY/kg（即 0.06 CNY/g），其他站点仍使用 10 CNY/kg。

```text
澳洲站空运单件头程(CNY) = 商品重量(g) × 0.06
澳洲站空运单件头程(AUD) = 空运单件头程(CNY) ÷ CNY/AUD 汇率
其他站点空运单件头程(CNY) = 外箱重量(kg) × 空运单价 ÷ 装箱数
经营利润率 = (我们的售价 - 全部成本) ÷ 我们的售价

采购税费 = 采购成本 × 4%；国内运费以商品实际重量计费，利润默认采用重量 × ¥5/kg，页面同时显示重量 × ¥2/kg 至重量 × ¥5/kg 的参考区间。两项均按商品独立保存并可在单品窗口调整。
```

澳洲 Excel 的头程公式不考虑体积，直接按商品重量和 0.06 CNY/g 计算，再除以汇率得到 AUD。澳洲站 FBA 配送费按用户确认的标准信封重量及售价档计算，加拿大站按旺季信封件表加 3.5% 附加费估算；两站的自动配送费采用各自表格，允许单品人工覆盖。其他站点缺少外箱重量或装箱数时，界面仍使用单件实际重与体积重取高的代理估算。

## 首页筛选

首页只保留四项：是否接入 SellerSprite、Amazon 页面月销量档位、最低评价数量、最低评价星级。候选需要同一 ASIN、同一站点的有效近月销量至少 50。关闭 SellerSprite 时，使用 Amazon 店铺卡片或当前商品页购买量提示，保存原文和 ASIN，并标记下限；开启时优先使用 competitor_lookup 返回的 amzUnit 子体近 30 天销量证据。缺失销量为未知，不能归为低于 50。默认包含全部合格的 50+ 商品，也可筛选 50 至小于 100、至少 100。没有有效证据、证据不匹配或仅有人工填写的销量均暂不进入候选；历史数据保留，但不继续匹配不合格商品。结果页调整筛选项后，点击“确认筛选”才刷新下方候选商品；“恢复默认”会立即恢复并刷新。商品重量只用于 FBA 费用计算和结果展示，不参与候选筛选。

筛选不会删除源 ASIN。所有成功或失败的 Amazon 商品页结果都会写入任务记录和导出数据；候选页分别显示待继续枚举的 ASIN 估算、Amazon 页头差异和当前筛选隐藏数量，并保留 `filterExclusionReasons`。用户关闭 SellerSprite 时，不使用销量、A+、上架日期、FBA 费等 SellerSprite 字段进行首页筛选。

Amazon 店铺访问与 1688 匹配是两个独立阶段。Amazon 完成并保存全部候选后，用户在结果页确认月销量、评价数和星级筛选，再显式创建 1688 固定批次；断线恢复只处理该批次保存的商品 ID，不会自动扩大到全部候选。

## FBA / FBM

- AU 自动值采用标准信封表，按实际商品重量和售价选择费用；CA 自动值采用旺季信封件表，按商品重量、售价优惠及附加费计算。见 [详细规则](docs/fba-rates-au-ca.md)。
- AU 的已知尺寸须符合标准信封限制；CA 来源表没有信封尺寸信息，估算不能作为尺寸合规证明。超出各自重量范围时由产品人员填写费用。
- 其他站点延续原有费率估算：优先使用 FBA 包装尺寸与重量，缺失时回退商品参数；当地费表缺失而采用美国数值的代理估算继续明确标记。
- 人工配送费优先，自动表格更新不会覆盖人工费用；页面确认缺重的最低费暂估允许初审。
- 产品人员可以手工覆盖 FBA 费用，也可以切换 FBM 并填写 FBM 履约费。
- 手工采购成本与履约费输入后实时计算经营利润率，并可直接“保存并初审通过”。

## 数据完整度

“分析后仅显示数据完整商品”默认关闭；开启时只临时隐藏不完整行，不删除保存数据。当前自动完整度检查包括：

- 源 ASIN；
- 店铺标识；
- 当前售价；
- 30 / 60 天销量；
- 评价数量与星级；
- A+ 状态；
- 竞品上架时间与首次 FBA 有货时间；
- 商品主图；
- 有效重量；
- 有效长宽高；
- 当前履约方式所需的 FBA / FBM 费用；
- 可计算经营利润所需参数。

字段不完整的商品始终保留，可手工补填并完成产品初审；导出全部候选时会连同缺失原因一起输出。

## 输入与站点

带表头的 XLSX 支持：

- `店铺链接` / `sellerUrl`
- `卖家ID` / `sellerId`
- `店铺名` / `sellerName`
- `ASIN` / `父ASIN` / `asins`

上传 XLSX 时，先按文件中的有效店铺链接识别国家，再自动切换当前站点：`amazon.ca` 对应 CA / CAD，`amazon.com.au` 对应 AU / AUD。界面原先选择的国家不会拒绝另一国家的有效链接，也不会改写其国家。一个文件包含多个有效站点时要求按国家分批；只有 Seller ID 且没有国家信息的行继承文件识别出的唯一站点，整个文件都没有国家证据时才使用当前界面站点。国家列与链接国家矛盾的行继续提示错误。有效新文件先完成旧任务保存归档，再切换新任务的站点、币种和默认汇率；空文件、无效文件或归档失败不会切换旧任务。详情仅使用任务对应站点；页面未提供价格、重量或月销量时分别保留缺项，不用其他站点数据替代。

每店沿 Amazon 返回的真实下一页链接扫描，安全上限为 25 页 / 500 个唯一 source ASIN。跨页去重；遇到验证码、风控或 429 会保存已发现结果和下一页位置，不刷新重试。每店推荐数量只影响推荐标签，留空表示不设推荐名额；全部源 ASIN 始终保留在候选列表、任务快照和导出数据中。

## 持久化与安全

任务快照保存在 `data/runs/`，索引和累计调用数保存在 `data/state.json`。重新打开页面会恢复最近任务，并保留历史任务、商品、成本、利润、报价证据和初审状态。

1688 会话数据始终保存在采购助手的 `data\1688-session`。升级找品 Agent 或采购助手时不得覆盖、删除或迁移该目录；发布文件清单不包含 `data`。

- 浏览器只能访问固定本地业务接口，不能指定任意 MCP 工具。
- SellerSprite MCP 地址、认证头、密码和 Cookie 不写入任务快照或导出表；独立本机配置文件和业务数据不提交 GitHub。
- Amazon 店铺链接会按站点和 Seller ID 重建并校验域名。
- SellerSprite 商品图片只允许从 Amazon 官方图片域名下载。
- 1688 候选图片只允许从受控的阿里 HTTPS 图片域名下载，并校验公开网络地址、大小、MIME 和文件签名。
- 供应商链接只允许显示 `https://1688.com` 或其子域名。
- 临时商品图片使用后立即清理。
