# v0.9.70：历史任务编辑、初审和导出

从任务记录载入已归档任务后，可以修改商品信息与人工成本、保存初审状态，再导出当前筛选的候选商品或已初审商品。Excel 文件名校验同时支持当前筛选名称和既有名称，修复“导出文件名无效”。可选 JSON 交接及其 Excel 使用相同的人工初审商品范围。

保存历史任务时保留其归档时间、原导入范围、Amazon 与 1688 采集状态；不会恢复采集，也不会切换另一任务的当前执行指针。归档前的旧页面回写仍会被拒绝，需要从任务记录重新载入。历史任务在打开时保留已有数据和初审结果，不自动迁移或重采。旧匹配状态不再阻挡人工编辑。

已经交接采购的商品保留交接快照，点击“创建新的分析版本”即可继续编辑和初审。其他电脑需要使用 v0.9.70 程序文件并重启服务、刷新页面；历史业务数据应保留。

回归验证覆盖归档任务两种编辑入口、初审、重新载入、普通 Excel 导出、JSON 与 Excel 交接、已交接商品的新分析版本、分块存储、服务重启后保留数据，以及旧页面回写和采集恢复的限制。API 测试使用独立临时数据与导出目录，禁止外部访问。
