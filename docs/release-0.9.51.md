# v0.9.51：上架时间、日期筛选与模板导出

## 商品上架时间

Amazon 商品详情采集在同一次访问中读取 Product information 中的 **Date First Available**，兼容已支持的英文和加拿大法文标签及日期。字段独立于 SellerSprite 上架日期、评论日期和采集时间，不用这些值推算或替代。

保存字段为 `amazonFirstAvailableDate`（`YYYY-MM-DD` 或空值）、`amazonFirstAvailableDateStatus` 与 `amazonFirstAvailableDateEvidence`。证据保留 ASIN、站点、原标签、原文和定位信息。状态为：

| 状态 | 含义 |
| --- | --- |
| `found` | 当前 ASIN 的商品信息中有可解析、无冲突的明确日期 |
| `not_provided` | 当前商品信息检查完整，未找到该字段 |
| `unresolved` | 尚未采集、检查不完整、日期无效或证据冲突 |

商品上架时间不是必填利润参数，缺失不会停止利润计算或额外触发网络访问。已有活动任务在启动时可以从保存的 Product information 补取缺失的新字段，不重新采集、不解除暂停。旧任务若未保存日期原文，日期保持未知；不能承诺升级后立即补齐历史商品日期。

## 前端日历筛选

在结果筛选中选择“商品上架时间”的起始日期，展示该日至本机日历今天之间的产品，**两端均包含**。日期未知、无效或未来的产品不纳入启用后的日期范围，并显示未知数量。清空日期即取消该条件。

日期条件与现有搜索、月销量、评分、利润和完整性筛选共同生效。它只筛选已有结果，不改变店铺采集范围或暂停状态。条件按任务隔离；保存的结果条件可随快照恢复，当前浏览器还在 sessionStorage 中保存选择，避免后台写锁期间丢失。新导入任务不会继承上一任务的日期。

“商品上架时间”指 Amazon 页面公开的 Date First Available；它不证明某位店铺卖家首次开始销售该商品的时间。

## Excel 格式

以用户提供的 `Scout_CA_已初审产品_20261013_100049.xlsx` 为格式参照：保留原 33 列的相对顺序，在“商品重量 (kg)”之后新增“商品上架时间”，合计 **34 列**。本币金额标题按当前任务站点使用 CAD、AUD 等币种。

保留商品图、固定列宽、Arial 10、深蓝表头、冻结首行、自动筛选和数据行高度。日期为真正 Excel 日期单元格，显示为 `yyyy-mm-dd`，未知留空；金额和比例保留数字类型。原表的比例单位为百分数，例如 15 表示 15%，不改成 0.15。原“数据采集时间”列仍位于最后。“商品重量”优先使用已保存的有效人工重量，没有人工覆盖时使用 Amazon 商品重量。

导出使用当前组合筛选结果；“已初审”导出还要求人工初审通过。JSON 采购交接保留日期证据和有效日期范围，继续保留原有人工确认和月销量资格约束。

## 升级与验证

升级前备份完整数据和配置。安装版在原安装目录运行新包的 `Install.cmd`；旧手工部署（例如 `D:\亚马逊选品`）不会被安装器自动识别和迁移，请勿把另一台电脑的 data、配置或登录档案覆盖到本机。

程序继续由本地 Node 服务和守护运行，不依赖 ChatGPT 或 WorkBuddy。无 SellerSprite 时继续使用 Amazon 模式。Amazon/1688 登录、访问验证或人工暂停需要用户自行处理；升级不会自动恢复这些任务。

回归包含日期解析与同 ASIN 证据、单次访问、保存数据迁移、暂停保留、组合筛选、导出范围、Excel 结构和日期单元格。日期正例使用明确标记的合成页面；真实保存页面用于验证未提供日期的情况，不宣称对全部 Amazon 页面均已验证。
