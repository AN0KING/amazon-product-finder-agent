# v0.9.53：当前 Excel 的 ASIN 采集范围

修复切换到“导入 ASIN”后，“开始采集”仍恢复旧店铺任务的问题。开始前先验证当前选择的输入；新输入验证通过后，保存并归档旧任务，再创建独立的新任务。仅切换标签不会访问 Amazon 或替换旧任务，取消或无效输入也不会触发旧任务恢复。

Excel 有 ASIN 列时，仅从该列取得商品范围，空单元格跳过并提示，不会从同一行的店铺链接或其他商品链接补入 ASIN。没有 ASIN 列时，可上传商品链接列，或无表头的单列 ASIN / 商品链接清单。无表头清单从第一行开始读取；商品链接的卖家参数不会扩大采集范围。纯 ASIN 使用所选站点，商品链接按域名识别站点，跨站点混合输入拒绝导入。

店铺 Excel 解析时同时保存来自原始文件的 ASIN 预览，以便切换模式和恢复页面时使用。旧版本快照没有这份原始输入证据时，需要重新选择 Excel；不能把旧任务发现的商品当作新文件内容。界面显示待采集的 ASIN 数量、来源与站点，无有效输入时禁用开始按钮。

新 ASIN 任务只访问清单内的商品，不枚举卖家店铺。旧任务和人工数据保留在历史记录中。升级本身不启动真实采集，也不会解除已有的人工暂停、访问验证或风控暂停。
