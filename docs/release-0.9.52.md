# v0.9.52：ASIN 导入、评价区间与详情识别

## 导入入口

首页可选择“店铺导入”或“ASIN 导入”。店铺清单沿用原有方式；ASIN 模式支持粘贴 ASIN、Amazon 商品链接，或上传 XLSX。纯 ASIN 使用所选站点，商品链接按域名识别站点，同一批次只接受一个站点。重复 ASIN 去重，最多 10000 个不同 ASIN（原始输入最多 20000 项）；无效或跨站点混合输入会提示修正，不覆盖当前任务。

解析和确认导入后，点击开始分析，直接访问这些 ASIN 的同站商品页，跳过店铺枚举，复用后台队列、暂停、保存和断点机制。切换输入方式或取消文件选择不会替换旧任务；成功导入前先保存并归档旧任务。导入本身不会访问 Amazon，也不自动连接 SellerSprite。

## 评价数量区间

“最小评价数”和“最大评价数”分别控制下限、上限，两端均包含；任一项留空代表该方向不限。仅接受非负整数，最小值不能超过最大值；0 与未取得评价数分开处理。启用区间后，未知评价数不判定为符合。

页面候选、后台查询、保存恢复和导出采用同一范围规则。店铺 Excel 可使用 `minReviews` / `maxReviews` 或“最小评价数” / “最大评价数”列；导入的店铺范围与页面范围取交集，无交集时提示规则冲突。

## 重量与上架时间

结构化读取当前 ASIN 的 Product information，兼容表格、列表、定义列表与标签/值布局；按分区滚动并展开 Item details、Measurements 等内容，在有限时间内等待加载稳定。商品重量与包装重量分别保留原文、来源和单位，Item Weight 140 g 换算为 0.14 kg；Load Capacity 4.54 kg 等承重量不会作为商品重量。

Date First Available 仅来自当前 ASIN 的商品信息。采用严格日期解析，日期无效、含糊或不同来源冲突时保留“待核验”；不使用评论时间、采集时间或 SellerSprite 日期替代。

找到明确有效字段即可保存；判定“页面未提供”则需要完整、稳定、同 ASIN 的浏览器检查证据。仅取得部分 HTML、未展开分区、加载未结束或旧证据不足时保持待核验。旧版不充分的缺失结论不再触发缺重最低 FBA 费暂估；人工重量、费用和采购报价仍优先保留。

升级不会自动重新采集旧商品，也不会解除人工暂停、验证码、登录或风控暂停。历史缺项是否能补齐，须在访问验证处理完成后按用户指定范围重新读取；不能根据修复代码推定历史商品已经取得新数据。

这些功能由普通本地程序执行，无需安装 AI skill。验证使用离线页面和隔离接口测试；遇到 Amazon 访问验证时不绕过或强制续跑。
