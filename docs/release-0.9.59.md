# v0.9.59：缺重商品按最低档暂估利润

按用户要求，全部 12 个已支持站点在商品重量未查到时继续计算暂估利润。待采集、访问失败、规格检查未完成与页面确认未提供重量均适用；缺少有效售价等其他必要参数仍保留待计算原因。

FBA 配送费使用当前站点模型的最低重量档及适用售价规则；国内运费和头程使用独立的估算重量。AU 为 75g，CA 为 100g，US 为 0.25lb。NL、UK、DE、FR、IT、ES、PL、MX、BR 延用现有美国 SOP 名义费率模型的最低档（3.22 当地货币单位、0.25lb），明确标记参考估算，不代表当地官方信封费率。AU 与 CA 的售价边界、优惠及附加费保持原规则。

真实重量保持未知，估算重量单独保存在利润输入与导出中，利润标记为暂估。查到有效 Item Weight 或填写人工重量后自动切回真实计费；人工配送费、采购成本、供应商报价和自定义费率保留，已移交采购的冻结记录不重算。显式 FBM 沿用其原有规则。

头程仍保留原模型的装箱重量和体积重规则；最低档重量只补足未知的商品重量，不覆盖有效装箱参数。

采集结果与数据质量独立保留：未完成的重量检查仍为待核验，不能因可计算暂估利润而改成已核验或页面未提供。此版本不宣称解决 B09NXS1BLL 普通 Edge 与采集会话返回不同规格行的问题，也不把用户提供的 110g 写成自动采集结果。

公式版本为 `profit-workbook-all-market-minimum-envelope-v12`。当前任务通过现有快照投影重算，无需新建批次、重置任务或补查预算。
