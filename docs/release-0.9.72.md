# v0.9.72 · 厂家选择与运营表

在商品详情的 1688 匹配页，每条有效厂家链接旁新增单选按钮，并提供手动链接输入框和保存按钮。每个商品独立保存两个选择，导出优先使用非空手动链接；清空手动输入后采用单选链接。选择链接不修改采购成本或已有利润结果。

历史任务也可保存厂家链接。刷新页面或再次载入任务时恢复原选择；重新匹配保留已选链接。进行中的采集/匹配与已交接采购商品仍遵循现有编辑保护。

运营表保留原有列，并新增厂家链接、亚马逊链接、ASIN、月销量、最低售价、人民币采购成本、国内物流费用、包含提货入库配置费的当地货币采购成本、佣金、FBA物流费、克重、空运头程、汇率折损费、Marketing、管理费、退货损失、VAT、总成本、总利润额、利润率。评分继续使用原有评分列。

最低售价读取已有“我们的售价”；费用列读取已保存的计算结果，不按参考图中的百分比重新计算，不生成公式。人民币费用以 RMB 标示，其他金额跟随任务站点货币；金额显示两位小数，重量由已知实际 kg 换算成 g。未知实际重量不以体积重替代。缺失数据填写“【请填写对应内容】”，真实的 0 保留为数值。未保存的链接会在导出前保存；链接无效或保存失败时停止导出并提示重试。
