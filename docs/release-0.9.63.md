# v0.9.63：夜间采集中断恢复

本次重点完善非人工中断后的自动恢复，沿用原任务和原 ASIN 范围。

- 主服务退出：确认本安装/项目归属后恢复，执行器读取保存的断点。
- Scout 进程仍在但无响应：连续 3 次被动版本检查失败，再次确认后替换本项目进程。
- 采集停滞：同一进程、同一可运行任务连续观察 15 分钟无进展，复核任务版本、暂停和资源占用后恢复。
- 店铺枚举网络失败：连续失败后的停止状态自动安排延长冷却，从原分页继续；不从第一页重跑。
- 问题商品：保持原有有限重试和额外两次补查，耗尽后保留错误并继续其余商品。
- 防循环：每小时最多 5 次服务启动，恢复记录持久保存；守护自身重启不会清零。
- 保护人工暂停、禁用、验证码、登录失效、风控、正常冷却和 1688 占用；不修改人工值、不创建新批次、不扩大范围。

检查只使用版本、采集和匹配状态接口，不调用 health、不授权 SellerSprite。安装版与源码启动器共用恢复探测逻辑。正常完成且无可补查项的任务不启动新采集。

验证通过采集器启动/状态接口及安装版 Supervisor.ps1 -Once 入口，使用隔离任务与随机端口服务；审查基线为本次开始时保存的工作区快照。没有同事故障现场日志，不能据此断定其夜间中断的唯一原因。

升级：完整解压后运行 Install.cmd，沿用同一安装目录；安装器保留 data、config、会话和导出。请先暂停正在运行的任务再升级。电脑关机或休眠期间无法采集；恢复运行后按保存状态继续。
