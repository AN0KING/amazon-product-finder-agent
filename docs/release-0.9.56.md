# v0.9.56：按页面提取、仅 Item Weight 与可选上架日期

## 页面身份与采集范围

继续按当前任务导入的 ASIN/链接访问并保存结果。页面主信息、canonical 或规格区显示的 ASIN 与输入不同，不再导致整件商品采集失败；这些差异保留为诊断信息。评价数、星级、Date First Available 和 Item Weight 从主商品内容提取。价格等既有利润输入继续正常采集。站点边界、推荐商品隔离、隐藏模板排除及访问验证暂停仍有效。

## 商品重量

商品重量仅采用规范化后的精确 `Item Weight` 标签。Package Weight、Shipping Weight、Item Display Weight、承载容量、尺寸尾部重量和 JSON-LD 重量不作为商品重量回退。

有多个 Item Weight 时按主商品信息区来源优先级选取：原生 Measurements/技术规格、其他结构化主商品行、旧详情列表。同等来源优先当前浏览器观测，保留采用的原文、位置、单位及其他观测用于追溯，不再将多个页面表示合并成阻断整件商品的重量冲突。

实际 B08YWZC4C6 的旧记录包含 `0.37 Pounds`（约 167.83g），浏览器 Measurements 显示 `170 Grams`。旧版跨通道合并与过窄容差导致误报；`Load Capacity 4.54 kg` 是承载容量，并非该商品重量。修复用已保存的实际页面证据回归验证。

商品缺少 Item Weight 时单独标记缺失，不能自动把包装重量冒充商品重量参与计费。人工重量仍优先，失败刷新保留原有成功数据。

## 上架日期

完整检查后没有 Date First Available 标注“Amazon 未提供上架日期”；尚未完成检查标注“上架日期待核验”。日期不再作为商品完整度的必填项，也不参与利润公式或默认候选分析。只有用户主动设置上架日期范围时，日期才影响该项筛选。价格、商品重量及必要成本齐全时照常计算利润。

原任务范围、人工价格、重量、采购成本和供应商报价保持原有保护。当前访问验证暂停须由用户处理，不因加载本次修复而自动解除。
