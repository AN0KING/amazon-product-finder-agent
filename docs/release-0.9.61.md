# v0.9.61：恢复 ASIN 月销量筛选

ASIN 导入曾隐藏月销量控件并绕过月销量规则。按用户要求撤回该行为：店铺和 ASIN 任务均显示可操作的筛选，支持有效月销量至少 50、50 至不足 100、至少 100。旧任务保留已选档位，重新打开时重新评估候选，不触发重新采集。

前端候选、后台筛选、1688 匹配资格、人工初审及交接恢复有效月销量至少 50 的要求。未知销量保持未知，原始 ASIN、人工数据、已完成供应商结果和采购交接记录不作迁移或删除。导入模式仍只决定采集范围。未知重量的最低信封档利润暂估规则不变。

回归覆盖两种导入方式、三个档位、旧任务恢复、销量证据来源、其他筛选、初审、导出、匹配固定范围及人工暂停。
