# v0.9.71：历史任务匹配 1688

在任务记录中载入历史任务后，可以点击“匹配当前筛选”继续 1688 图片匹配，也可以在商品详情中点击重新匹配，仅处理该商品。报价和利润写回原历史任务，完成后可继续编辑、初审和导出。历史任务仍保留原归档时间、Amazon 采集状态、导入范围以及已有商品数据。

只有明确选择历史商品后，后台才允许匹配该历史任务。普通打开历史任务不会自动重新采集。批量匹配保留已有报价、失败次数及任务编号；单件重新匹配保留此前任务记录，并仅为指定商品开始新的匹配。已经交接采购的商品需先创建新的分析版本；人工采购成本和已淘汰商品仍不加入自动匹配。

后台使用现有 1688 队列，保留每 60 分钟最多 70 次、启动间隔至少 51429 毫秒、并发 1、平台冷却及人工验证暂停。其他任务已有匹配时，会提示先处理当前任务。历史任务再次被新上传替换时，停止其匹配并阻止迟到结果回写。关闭页面不影响已明确启动的后台匹配，服务重启可恢复其断点，验证暂停不会自动解除。
