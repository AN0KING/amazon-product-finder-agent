# v0.9.62

ASIN 导入默认显示全部候选商品，月销量低于 50 或未知不再自动隐藏。月销量筛选继续显示并可用；主动选择至少 50、50 至小于 100、至少 100 时才应用对应限制。店铺导入保留原有有效销量 ≥50 的默认规则。

候选计数、后台筛选、采购候选和初审交接使用一致的导入方式与已保存销量条件。未知销量仍为未知，不改写证据，不重采、不重置任务，也不自动启动采购匹配。

商品数据筛选改为紧凑的五列布局：月销量、最小评价数、最大评价数、最低星级和上架日期在桌面端同一行，标签与输入框统一对齐。窄屏保留可用布局。

验证包括前端、ASIN 后端、采购队列和交接规则的回归测试，以及隔离 Edge 中的筛选交互和布局检查。
