# v0.9.54：ASIN 导入跳过月销量初筛

> 历史记录：此行为已在 v0.9.61 按用户要求撤回。当前 ASIN 与店铺导入均恢复月销量筛选。

ASIN 导入的采集范围由用户直接指定，商品采集后直接进入候选列表。月销量为 0、不足 50、未知或暂未取得时，不再因此排除；历史任务残留的月销量档位也不限制 ASIN 直采任务。月销量仍正常读取并显示真实值与来源，未知不会改成 0 或伪造为合格销量。

任务以已保存的 `inputMode: "asins"` 识别直采模式，仅切换导入标签不改变旧任务的筛选规则。已有 ASIN 任务刷新页面后即可使用新显示规则，无需再次采集。评价数区间、星级、日期、重量、完整度等用户显式选择的条件仍然生效。

候选计数、初审、手动导出及用户确认范围后的 1688 匹配采用相同的 ASIN 月销量规则，避免商品显示后又因同一销量门槛被下游排除。店铺导入继续使用原有月销量初筛。

本次升级不新建采集、不补采缺项、不修改真实销量或人工数据、不改变 1688 速率和已确认的匹配范围。
